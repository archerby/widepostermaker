# Mobile UX + Analytics Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make widepostermaker.com usable on a phone (compact header, sticky download bar, collapsible settings, 16 px / 44 px touch rules) and add optional cookieless Cloudflare Web Analytics.

**Architecture:** Static site built by `scripts/build.py` (stdlib SSG) from `templates/*.html` + `content/i18n/*.json` + `content/pages/*/*.json`. The tool runs as vanilla ES modules (`src/js/app.js`). Mobile behaviour is CSS-first (`<details>` menus, media queries, `position: sticky`); JS only adds the stepper, opens "More settings" on desktop and fills the bar summary. Analytics is a build-time switch driven by `content/site.json`.

**Tech Stack:** Python 3.10+ stdlib (build), vanilla JS/CSS, pytest + headless Chrome (`tests/test_e2e_browser.py`), PyMuPDF/pypdf.

Spec: `docs/superpowers/specs/2026-11-22-mobile-ux-design.md`. Branch: `mobile-ux`.

- build: `python scripts/build.py`
- fast tests: `python -m pytest -q tests/test_build_and_seo.py`
- browser tests: `python scripts/build.py && python -m pytest -q tests/test_e2e_browser.py`

```python
BEACON_TOKEN_RE = re.compile(r"^[0-9a-f]{32}$")
CF_SCRIPT_ORIGIN = "https://static.cloudflareinsights.com"
CF_CONNECT_ORIGIN = "https://cloudflareinsights.com"


def _check_token(token: str) -> str:
    if token and not BEACON_TOKEN_RE.match(token):
        raise ValueError("content/site.json: cfBeaconToken must be 32 lowercase hex chars")
    return token


def build_csp(token: str = "") -> str:
    _check_token(token)
    script_src = "'self'" + (f" {CF_SCRIPT_ORIGIN}" if token else "")
    connect_src = "'self' blob:" + (f" {CF_CONNECT_ORIGIN}" if token else "")
    return (
        f"default-src 'self'; script-src {script_src}; style-src 'self'; "
        "img-src 'self' blob: data:; worker-src 'self' blob:; "
        f"connect-src {connect_src}; font-src 'self'; object-src 'none'; "
        "base-uri 'self'; form-action 'none'"
    )


def analytics_snippet(token: str = "") -> str:
    if not _check_token(token):
        return ""
    return (
        f'  <script defer src="{CF_SCRIPT_ORIGIN}/beacon.min.js" '
        f"data-cf-beacon='{{\"token\": \"{token}\"}}'></script>"
    )


def render_mobile_nav(nav_items: list[dict], active_route: str) -> str:
    links: list[str] = []
    for item in nav_items:
        href = validate_href(item["href"])
        current = ' aria-current="page"' if href == active_route else ""
        links.append(f'          <a href="{esc(href)}"{current}>{esc(item["label"])}</a>')
    return "\n".join(links)


def render_mobile_lang(i18n_map: dict[str, dict], current_locale: str, slug: str) -> str:
    links: list[str] = []
    for loc in LOCALES:
        href = route_for(loc, slug)
        current = ' aria-current="page"' if loc == current_locale else ""
        links.append(
            f'          <a href="{esc(href)}" hreflang="{esc(loc)}" lang="{esc(loc)}"{current}>'
            f'{esc(i18n_map[loc]["codeLabel"])}</a>'
        )
    return "\n".join(links)
```

  function stepValue(dir) {
    const step = Number(els.sizeValue.step) || 1;
    const min = Number(els.sizeValue.min);
    const max = Number(els.sizeValue.max);
    const cur = Number(els.sizeValue.value);
    const base = Number.isFinite(cur) ? cur : min;
    let next = Math.round((base + dir * step) / step) * step;
    if (Number.isFinite(min)) next = Math.max(min, next);
    if (Number.isFinite(max)) next = Math.min(max, next);
    els.sizeValue.value = String(Number(next.toFixed(2)));
    els.sizeValue.dispatchEvent(new Event('input', { bubbles: true }));
  }
  els.btnStepDec.addEventListener('click', () => stepValue(-1));
