# SEO Wave 1 Implementation Plan

> **For agentic workers:** executed inline by the session that wrote it (superpowers:executing-plans); content tasks C1–C4 are delegated to language sub-agents, D to an editor sub-agent. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 4 new tool landing pages × 5 locales, thicker localized pages, computed size tables, preset chips, related-tools links, full footer tool list, cache-busted assets.

**Architecture:** content stays in `content/pages/<loc>/<slug>.json`; new optional page keys `chips`, `related`, `sections[].autoTable` are rendered by `scripts/build.py`; geometry for tables lives in `scripts/sheetcalc.py` (port of `src/js/layout.js`) and is parity-tested against the real JS in the headless-Chrome e2e.

**Spec:** `docs/superpowers/specs/2026-11-22-seo-wave1-design.md`. **Branch:** `seo-wave1`.

### Task A1: `sheetcalc.py` + parity test

- [ ] Port: `resolve(paper, orientation, margin, overlap)` and the `scale`-mode branch of `solveGridForOrientation` with `orientation='auto'` (portrait vs landscape: fewer sheets wins; tie → smaller waste; tie → portrait for a portrait poster). Poster sizes: A0 841×1189, A1 594×841, A2 420×594, A3 297×420 (mm). Paper defaults: a4/a3 → (5, 10), letter/legal → (6, 12).
- [ ] Python sanity test (hand-checked): A1 on A4 portrait with 5/10 → printW 200, stepX 190, printH 287, stepY 277 → cols = ceil((594−10)/190)=4, rows = ceil((841−10)/277)=3 → 12 portrait; landscape: printW 287, stepX 277, printH 200, stepY 190 → cols ceil(584/277)=3, rows ceil(831/190)=5 → 15 → **A1 on A4 = 4×3 = 12**. Assert this exact value.
- [ ] e2e runner: compute the same 4×3 matrix (posters × a4/letter/a3) with `computeLayout({srcWidth: w*10, srcHeight: h*10, srcPhysWmm: w, srcPhysHmm: h, isVector: true, paper, orientation:'auto', mode:'scale', value:100, marginMm, overlapMm})` and return `{key: [cols, rows]}`; Python asserts equality with `sheetcalc`.

### Task A2: build features

- [ ] `autoTable` renderer (headers from `i18n.tables`: poster, size, one column per paper; cell `"{cols} × {rows} = {n}"`; `<caption>` with margin/overlap assumptions). Sizes printed as `59.4 × 84.1 cm` and `23.4 × 33.1 in`.
- [ ] `chips` renderer: `<div class="chips" aria-label="{chipsLabel}"><a class="chip" href="?{query}" data-preset="{query}">{label}</a>…</div>`; `query` validated against `^(?:[a-z]+=[a-z0-9.]+)(?:&[a-z]+=[a-z0-9.]+)*$` and allowed keys `paper|units|cols|rows|width|scale|mode|ori`.
- [ ] `related` renderer: `<nav class="related" aria-label="{relatedHeading}"><h2>…</h2><div class="related-grid"><a class="related-card" href="{route}"><strong>{h1}</strong><span>{description}</span></a>…</div></nav>`; unknown slug → `ValueError`.
- [ ] Footer tools = every `template == "tool"` page of the locale in sitemap order, label = `navLabel` if present else `breadcrumbTitle`.
- [ ] `cache_bust(dist)`: hash of all `dist/css/*.css` + `dist/js/*.js` (sorted, bytes) → `H[:10]`; replace `href="/css/style.css"` / `src="/js/app.js"` in every `*.html`; regex-replace `(from\s+|import\()(['"])(\./[a-z0-9-]+\.js)\2` in `dist/js/*.js` with `?v=H`.
- [ ] `app.js`: `document.querySelectorAll('.chip[data-preset]')` click → if a source is loaded, `preventDefault`, parse params, set `paper/units/mode/value/ori` exactly like the initial query-param branch (refactor that branch into `applyParams(params)` and reuse it), `recompute()`; else let the link navigate.
- [ ] Tests (fast suite): SLUGS from content dir (10), new-page words ≥ 500, all pages ≥ 400, related resolve + ≥ 2 inbound links per new page, every `?v=` hash identical and target exists, `resolve_dist_target` strips query.
